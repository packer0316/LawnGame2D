# 月斷・月下影殺

刺客第七格全圖大絕，`skill_0048`。開發模式按 **7**；實際模式依原有技能掉落／消耗規則取得。冷卻 30 秒、價格 ×20，沿用既有八段全圖擊殺判定。

## 基礎分鏡（沿用 v4 時序）

2026-10-16 依使用者要求取消 Z 字，重新設計成月夜影分身暗殺。主色為銀白、月藍與淡紫，保留畫面留白；不再使用雷電拖尾、水墨翻捲或全屏路徑。玩家原地結印指揮，分身按地圖各層的怪群分批現身，最後收刀引爆。

| 遊戲時間 | 演出 |
|---|---|
| 0–620 ms | 暗場、忍者結印特寫，閉眼聚能 |
| 620–850 ms | 赤瞳睜眼、特寫推近 |
| 850–1600 ms | 巨型月亮被切開，上下切面超出畫面；鏡頭拉遠顯示全圖 |
| 1600–2940 ms | 三波月影刺客現身、拔刃留下月印、化成碎瓣；最多六個分身，分布於不同怪群 |
| 2770–3000 ms | 玩家原地收刀，支援原裝／蒼影忍裝／白隼刺客服 |
| 3120、3240、3350、3450、3540、3620、3690 ms | 七段全圖月刃，斬痕角度交錯，每次命中只停 8 ms |
| 3910 ms | 第八段重終結，月刃綻開成銀藍碎瓣、低頻重音、105 ms 停頓 |
| 4090–4400 ms | 暗場與鏡頭平順恢復，交還操作 |

一般命中不重複堆疊花形爆炸，使用短月刃序列；碎瓣綻放留給最後一擊。分身階段為預備留印，怪物受擊、數字與真正命中粒子都在收刀後的既有傷害事件同步觸發。

## 接入與規則

`MoonExecutionTiming.ts` 保存時序及分身選點。選點使用地圖比例距離，最多六處，避免同一密集怪群重複堆疊；六個分身是視覺演出數量，八次實際攻擊仍透過 `content/class/skills.json` 的 map 範圍選取最多 1000 個合法目標。

`MoonExecution` 的序列、鏡頭與音效共用遊戲固定時鐘，背包暫停與命中停格不偷跑。`applyHits → contact` 才播放真正受擊序列。原玩家依原有物理規則留在原位，只有收刀階段改用對應套服的專用替身。

連擊、傷害、押注、掉落與 RTP 不變，不保證每隻怪都死亡。切職業、換房與場景銷毀會清理演出物件並恢復人物及鏡頭。

`node scripts/moon-execution-review.mjs` 使用 `LAWN_REVIEW_URL`（預設 `http://127.0.0.1:5183`），檢查第七格啟動、巨型斷月、分身分批現身與退場、八段命中、三套收刀外觀、暫停及中途切職業／場景清理。截圖與報告輸出到 `art-review/moon-execution/`。
