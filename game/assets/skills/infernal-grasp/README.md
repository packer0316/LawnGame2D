# 冥獄之握

2026-10-16。法師第八格大絕 `skill_0049`，開發模式按 **8**。冷卻 40 秒、價格 ×20、滿價目標 20，八段全圖攻擊沿用既有判定／扣注／掉落系統；不保證擊殺。原人物以 `mage_cast` 循環施法，另有專屬法師半身動畫。

| 時間 | 演出 |
|---|---|
| 0–1120 ms | 暗紫地獄濾鏡、法師聚能／睜眼／張手的無框特寫 |
| 950 ms 起 | 巨手每隔 105 ms 從最底層伸出，各自上升 720 ms；鏡頭拉遠涵蓋全圖 |
| 2400–2950 ms | 手指張合、手腕左右緊繃掙扎，等待握拳指令 |
| 2720–3140 ms | 左側短暫出現法師握拳下令特寫；依回饋移除黃色框線 |
| 3100／3270／3430／3580／3720／3850 ms | 巨手錯開猛捏，八段中的前六段命中，每段 32 ms 卡肉 |
| 4030 ms | 巨手一同握緊、追加重捏 |
| 4320 ms | 最後全圖金紫冥焰爆裂，115 ms 重停頓與鏡頭微推近 |
| 4520–4950 ms | 巨手沉回地下，暗幕、鏡頭與操作恢復 |

`graspAnchors` 依地圖寬度排列 4–8 隻巨手（一般地圖為 6 隻），在各 x 位置選擇 y 最大的實際地形，包含斜坡。巨手大小及高度略有變化，按柱位留白排列；使用來源裁切遮住地底部分，避免從上層平台出土。巨手的局部爆光按演出時間出現，怪物受擊爆光只由實際接受的命中觸發；空場仍會完成握拳演出，但不產生額外傷害或連擊。
