## 命中序列

| 素材 | 適用招式 | 演出 |
|---|---|---|
| `archer-hit-sequence-v9.png` | 單箭、穿透箭、箭雨、三連射、後空翻射擊、萬箭齊發 | 8 幀 / 240ms；金白穿刺核心、青綠羽狀碎光、短壓力波、消散餘光 |

兩張皆為 1774 × 887 RGBA、4 欄 × 2 列。使用 imagegen skill 的 built-in 模式生成，透明 alpha 原樣保留；[原始提示詞](archer-hit-prompts-v9.json)。

核心尺寸依打擊強度為 `126 + power × 32` 世界像素，普攻約 140px。最前四個目標附短光暈與少量碎光；其餘目標仍完整播放核心序列，避免大量怪物造成滿屏細線。

投射物的實際飛行角度一路傳入 `applyHits → SkillFx.contact`；光箭爆發沿飛行方向，箭雨朝下，穿透箭等範圍招依角色面向。上射與落箭也統一經 `orientSkillWeapon` 校正方向。

普通箭矢增加淡殘影、青綠碎光；火箭增加橙色餘燼。拖尾每 55ms 取樣、殘影 110ms 回收；不增加箭矢數、傷害或判定次數。

## 全職業命中覆蓋

原本 `contact()` 只為前 5 個目標（末段 10 個）畫命中特效，現在每個可見、實際命中的目標都有核心回饋。離開畫面的目標仍照原戰鬥規則判定，僅略過畫面外渲染。

- 劍士與法師保留各自既有職業命中樣式。
- 刺客飛鏢保留金色命中序列；已確認的命中不再被 28px / 90ms 的空間去重吞掉。旋轉飛刃的額外視覺接觸仍保留去重，控制重複粒子。
- 其他刺客招式保留其技能風格。
- 弓箭手全部八招進入專用序列。穿透箭移除重複的舊式線條命中層。
- 空揮不生成命中核心；箭矢碰到怪物時才觸發。受擊閃白、後仰、傷害文字、命中停頓與鏡頭震動繼續沿用共用命中流程。技能資料、擊殺率、押注及強度規則未修改。

## 驗證

`node scripts/archer-hit-review.mjs`：34 個技能、112 個 strike，每段檢查 23 個目標，共 2,576 個命中回饋；空目標沒有命中核心。弓箭手八招 × 左右朝向共 16 組實際 `onStrike` / 投射物碰撞測試，兩張序列均完整觀察到幀 0–7；箭雨朝下、投射物爆發方向正確，清除後物件為零，無 page error。

截圖與 JSON 報告：`game/art-review/archer-hit-*`（不進版控）。瀏覽器檢查將測試伺服器回覆固定為存活，以便重複觀察同一批怪物；並非傷害或 RTP 統計測試。

`npm run typecheck`、全套 121 項測試與 `npm run build -w @lawn/web` 通過。建置仍有既有主程式 chunk 體積提醒。
