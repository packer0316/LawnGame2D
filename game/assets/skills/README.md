### 重量與節奏修訂（v5）

地裂動作速度 0.64×，可取消時間 1850ms；中段命中停頓上限 48ms、最後 100ms。突刺動作 0.6×，520ms 啟動既有程式衝刺、280px 位移分 360ms 完成，780ms 判定、1280ms 可取消；劍壓播放方向由面向鏡像。兩招保留原有判定形狀與段數。

## 接入與維護

### 雷焰白虎修訂（v6）

使用者最新指定：**本體全程不透明、啃咬不停住移動**。保留原名與技能 ID `skill_0009`，替換原月牙劍氣演出。白虎原畫由內建 imagegen 製作，原檔 `tiger-sequence-v6.png`、最終提示詞 `v6-prompts.json`；沒有使用 API fallback。

- 施放時取玩家所在樓層與可見地圖左右邊界，靠左從左進場、靠右從右進場；中線採左側。方向不依角色面向，後續鏡頭變動也不重算。
- 以 360px 圖格展示，頂層依上方空間等比例縮小；沿同層地面小幅起伏，平台缺口維持原樓層高度，不落到其他樓層。
- 600／1000／1400／1800／2200ms 五次啃咬，跑步位移持續推進；刪除咬合前後的減速停留點，命中停格為 0ms。咬合格與判定共用固定時間步，普通震動與怪物受擊回饋保留。
- 本體使用正常混色、alpha = 1。只讓尾後殘影淡出；退場時先越過另一側，完全離開畫面後才使用消散原畫。2950ms 完成離場，3050ms 可取消／接下一招。
- 電弧採背脊、肩胛、前後肢及尾部的短曲線錨點，疊細白芯、藍色光暈與短分岔，80–165ms 消失；跟隨虎身移動。沒有貫穿整隻白虎的水平長折線。
- 判定從原來玩家前方矩形，改為沿白虎路線分段取嘴部／前爪接觸帶，僅選同層怪物。每段最多 6 個目標，仍為 5 段，沿用每命中段扣一注。
- `TigerRoute.ts` 管理方向、路線、逐格姿勢與判定帶；`TigerSummon.ts` 管理白虎、雷焰與殘影；`GameScene` 只接入固定時間步及此技能的目標篩選。換房、切職業或 clear 都清除白虎與衍生特效。

- `SkillAtlas.ts`：預載圖集與全域動畫，重進場景不重複註冊；素材載入失敗會回報錯誤。
- `SkillFx.begin/release/play/contact`：依序負責起手、投射物出手、技能命名事件、實際命中回饋。
- `SkillVfxKit.ts`：柔光、細粒子、煙塵、拖尾、聚能、衝擊星芒及背景壓暗。
- `SkillPresentation.ts`：四職業色系、粒子預算與停頓規則。一般連擊中段最多 22ms，地裂重擊中段 48ms，快速連鎖最多 10ms，終結最多 105ms，單次重擊最多 115ms；震動最多 7 世界像素，垂直幅度較低。
- `SkillAudio.ts`：使用者首次點擊／按鍵後解鎖合成音；職業各自音高、撞擊噪聲與蓄力音，尊重 mute／volume，音量為零不建立音源。
- 特效只篩選視野內裝飾，**不影響全地圖傷害**。粒子預算 220、主裝飾預算 380；光源總量到 12 時略過新增光源。`__lawnStats().skillFx` 可檢查活動物件數。
- 原畫使用透明 PNG，新增武器與四組序列後首載素材量增加，瀏覽器可快取；這是高品質原畫首版，尚未做行動裝置壓縮版本與手機 GPU 效能認證。
