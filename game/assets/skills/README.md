# 技能特效與演出紀錄

2026-10-15。這批已接入遊戲的 `SkillFx`，沿用現有角色與 Claude 的逐段判定機制，依使用者要求增加連擊段數。共覆蓋 **34 筆技能資料**（含劍士三段普攻），提供序列原畫、聚能、拖尾、命中火花、煙塵、短暫壓暗、分段停頓及合成撞擊音。

[逐幀預覽](preview.html) 可選擇素材、播放／暫停、切換朝向及逐幀檢查。原畫與生成提示詞保存在本目錄；`reaper.png` 只保留為設計參考，遊戲不再載入這張靜態圖。

## 死神召喚（skill_0043）

| 技能時間 | 事件 | 演出 |
|---|---|---|
| 0ms | 起手 | 全畫面冥界濾色、72% 暗場、鏡頭邊緣漸暗；維持到終結爆發 |
| 410ms | `summonCircle` | 地面召喚陣、向上吸引的靈光；法陣保持水平 |
| 700ms | `reaper` | 格 0–5：霧中現身、起身、舉鐮蓄勢；依 `leadMs` 播放並停在蓄勢格 |
| 1100／1340／1580／1820／2060ms | `reaperSweep` × 5 | 每次重播格 6–9 的揮鐮收勢；怪物身上播獨立 8 格鬼爪、骷髏與魂霧序列 |
| 2400ms | `darkBurst` | 格 10–11：身體化霧、靈火消散；目標暗影爆發與終結重停頓 |

時間來自目前技能資料。揮鐮及消散由實際 strike 事件啟動，不能用「召喚後固定幾毫秒」猜命中時刻，避免 hit stop 累積造成錯拍。召喚位置為玩家面向前方 200px，腳底取當地地面；固定底部錨點 `(0.5, 1)`，展示大小 360 × 360 世界像素，左右使用鏡像。角色本身沒有 tween 位移或旋轉來冒充揮鐮。中斷時有逾時清除，換房及場景關閉直接銷毀。

## 接入與維護

- `SkillAtlas.ts`：預載圖集與全域動畫，重進場景不重複註冊；素材載入失敗會回報錯誤。
- `SkillFx.begin/release/play/contact`：依序負責起手、投射物出手、技能命名事件、實際命中回饋。
- `SkillVfxKit.ts`：柔光、細粒子、煙塵、拖尾、聚能、衝擊星芒及背景壓暗。
- `SkillPresentation.ts`：四職業色系、粒子預算與停頓規則。連擊中段最多 22ms，快速連鎖最多 10ms，終結最多 105ms，單次重擊最多 115ms；震動最多 7 世界像素，垂直幅度較低。
- `SkillAudio.ts`：使用者首次點擊／按鍵後解鎖合成音；職業各自音高、撞擊噪聲與蓄力音，尊重 mute／volume，音量為零不建立音源。
- 特效只篩選視野內裝飾，**不影響全地圖傷害**。粒子預算 220、主裝飾預算 380；光源總量到 12 時略過新增光源。`__lawnStats().skillFx` 可檢查活動物件數。
- 原畫使用透明 PNG，新增武器與四組序列後首載素材量增加，瀏覽器可快取；這是高品質原畫首版，尚未做行動裝置壓縮版本與手機 GPU 效能認證。

## 驗證

`node scripts/skill-signature-review.mjs` 另檢查大型岩刺、衝鋒、青龍、落雷、噬魂與縮小風魔的實機畫面。四組新增序列已觀察到所有格 0–7，自動回收歸零，普攻飛鏢顯示寬度為 48px。`v3-review` 實機紀錄亦確認死神有五次揮鐮及完整 12 格本體動畫、濾鏡維持至終結；劍氣左右鏡像符合發射方向。手機 GPU 與所有螢幕比例仍需另外實機調校。

在 `game/` 執行 `npm run typecheck`、`npm test -- engine/src/feel/SkillPresentation.test.ts engine/src/feel/skills.test.ts engine/src/actor/Player.test.ts` 及 `npm run build -w @lawn/web`。

瀏覽器回歸檢查包含：全部 34 筆技能依真實 cue／strike 時序播放表現事件、播放後物件歸零、死神 12 格播放、各職業技能鍵觸發、換房中斷清除。截圖與報告放在忽略版控的 `game/art-review/`。表現層重播不等同於傷害／RTP 測試；戰鬥行為沿用既有測試。

本機啟動遊戲後，在 `game/` 執行 `node scripts/skills-review.mjs` 與 `node scripts/skill-integration.mjs`。預設連線 `http://127.0.0.1:5176`，可透過 `LAWN_REVIEW_URL` 環境變數指定其他本機埠號。兩個腳本使用已安裝的 Chrome／Edge；整合檢查已確認 28 個主動技能由鍵盤啟動、死神幀 0–11 完整出現、演出結束及換房後 `skillFx = 0`，沒有 page error。型別檢查、全套 92 個單元測試與 production build 通過；build 仍有既有主程式 bundle 體積提醒。
