# 紫焰覺醒・鳳羽天劫

弓箭手第 8 格大招，skill_0050。開發模式按 8；實際模式沿用技能掉落與消耗流程。

## 美術

以白紫光芯、紫焰與深靛羽毛呈現，與既有金色箭雨分開。人物沿用棕髮旅人的臉型，覺醒演出為綠披風弓手；目前這組專屬演出不隨套服換裝。

- portrait-v1.png：4×3、12 幀。閉眼、紫瞳點亮、上半身展現、向上拉弓。前四幀另取眼睛裁切作特寫。
- caster-v1.png：4×2、8 幀。場上角色向天空拉弓、放箭、收勢。播放時暫時隱藏原角色，結束或中斷恢復。
- phoenix-v1.png：4×4、16 幀。前四幀垂直升空，其餘十二幀循環振翅；右上角登場時鏡像朝向場內。
- effects-v1.png：4×4、16 幀。四幀燃燒羽彈、十二幀命中爆發與餘燼。

均使用內建 image_gen 產生透明 PNG；原始輸出保留，來源與完整提示詞見 prompts-v1.json。讀圖時使用明確列邊界排除相鄰幀的尾羽，不改動原圖。

## 最終節奏（遊戲時間，毫秒）

| 階段 | 時間 | 表現 |
|---|---|---|
| 覺醒 | 0–1220 | 眼睛特寫 → 上半身 → 朝天拉弓，背景壓暗 |
| 場上放箭 | 820–1660 | 全身拉弓序列；1200 毫秒鳳凰從玩家上方垂直升空 |
| 出畫與展翼 | 1920–2400 | 完整離開畫面後，2100 毫秒於靠近玩家的上角重現 |
| 連續發射 | 約 2300–4720 | 不分波次；56 組羽彈連續射出，每組最多鎖定三隻不同活怪，另加一枚氣氛羽彈 |
| 密集命中 | 2850–5325 | 每 45 毫秒接力命中，輪巡全圖各層；只對該組羽彈鎖定、仍存活的怪物判定 |
| 收尾 | 5325–5950 | 最後命中短頓、鳳凰振翅升離、鏡頭與亮度恢復 |

羽彈採三次貝茲弧線，先向外慢速展開，再轉向並加速追敵。時間進度 p = 0.12t + 0.88t³；前 40% 飛行時間只走約 10% 曲線參數，後半段快速俯衝。飛行約 495–605 毫秒，連續平滑變化，避免固定間隔整排齊射。每幀更新存活目標位置；已死亡目標不再傷害，羽彈在最後追蹤位置消散。

共 56 個判定時點，每次上限三隻，不是每次瞬間打全圖。傷害／扣注仍走 GameScene.applyHits 與原有 LocalServer；price=20、fullTargets=3，沿用分段分攤公式。中段不全局停格，僅低幅間歇震動；末段 85 毫秒停頓。飛行、命中、開背包暫停都使用同一固定遊戲時間。

音效使用現有素材重新編排成專用 phoenix cues：覺醒、升空、登場、振翅、連續羽彈、命中、終結。中段抑制全屏閃白，保留怪物與曲線彈道的可讀性。
