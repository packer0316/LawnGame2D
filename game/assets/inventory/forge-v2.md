## 演出時序

1. 預載全部四張圖片，所有結果一視同仁。載入失敗可返回工坊，不消耗卷軸。
2. **共同蓄能 2.64 秒**：12 張美術關鍵影格，以瀏覽器更新率連續補間（60 Hz 下約 158 個播放畫面）。武器懸於神聖法陣中央；三種機率、所有結果的蓄能動畫、色調及節奏完全相同。此段尚未執行隨機判定。
3. 蓄能完畢才送出一次原有 `inventory/upgrade` 指令，消耗卷軸與強化次數。等待回覆時保持共同法陣最後一格。
4. **結果揭曉 1.56 秒**：12 張關鍵影格同樣連續補間（60 Hz 下約 94 個播放畫面）。此刻才切換成功／失敗動畫及結果文案；成功顯示增值，失敗明確區分武器保留或損毀。
5. 播完淡出特效，按「返回工坊」回到更新後的背包。

演出期間隱藏並鎖住其他工坊操作，保留開始前的背包快照，防止商人對話、武器數值或卸裝變化提前洩漏結果。按住或連點不會重複交易。背景分頁暫停演出計時；低動態偏好採代表格與相同等待時間。演出前重新整理不消耗；送出交易後沿用原有即時存檔規則。

## 接入與驗證

- `web/src/forgeArt.ts`：素材與時長集中設定。
- `web/src/ForgeSequence.tsx`：依浮點播放進度，對相鄰兩張影格做光場混合補間；`plus-lighter` 保持交接亮度，避免普通透明度疊加造成週期性變暗。每次畫面更新只改兩個特效圖層，不讓整個背包跟著重新渲染。這是即時補間，不是新增手繪動作格。
- `web/src/ForgeRitual.tsx`：載入 → 蓄能 → 等待 → 結果 → 返回狀態機。
- `web/src/InventoryPanel.tsx`：鎖住工坊、擷取快照及送出既有交易。
- `scripts/forge-review.mjs`：實際瀏覽器測試成功、失敗保留、損毀，逐格播放、共同前段無抽籤／無扣卷、連點只交易一次、背景暫停、鍵盤焦點、直橫向手機與低動態模式。截圖與報告輸出於忽略追蹤的 `art-review/`。
