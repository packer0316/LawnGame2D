# 工坊原位強化演出 v3

2026-10-16。取代 v2 全面板演出，不再隱藏行囊，也不需要按「返回工坊」。

## 節奏與美術

- 聚能 1,050 ms：武器原位描光、同心符文環、對稱光柱與向內收束的星芒。
- 揭曉 850 ms：成功為金白爆光、擴張光環和鑽星；失敗為冷銀碎光沉降，武器保留；損毀時額外褪色消散。
- 完整演出約 1.9 秒，結果後自動恢復操作。商人對話保留最終結果供閱讀。
- 改用 Canvas 逐畫面繪製連續幾何光場，不再混合 v2 位置與形狀不一致的序列幀。圓環與符文共用圓心／透視平面。
- 透明特效層跟隨原武器展示區的位置，允許超出展示框；捲動與視窗縮放時重新對齊。商人、收藏與卷軸仍可見，演出中暫停操作。
- 遵循降低動態效果偏好，使用靜態光場，不做抖動或縮放。

## 音效

使用現有 `SfxEngine` 與素材重新混音，共用音量與靜音設定；不另開 AudioContext。

| 事件 | 時點 | 音色 |
|---|---|---|
| `forge:charge` | 聚能起始 | 短蓄力、輕魔法風聲 |
| `forge:success` | 成功揭曉 | 明亮鐘聲、泛音與星光尾音 |
| `forge:failure` | 失敗揭曉 | 低落提示音、下沉魔法氣流 |
| `forge:destroyed` | 損毀揭曉 | 低落提示音、輕碎裂聲 |

## 交易與接線

- `InventoryPanel.tsx` 固定原物品快照並防止連點；`ForgeRitual.tsx` 在聚能結束後只送出一次 upgrade。
- 聚能期間不抽成功率，不提前更新物品／卷軸，不提前播放結果音色。
- `ForgeSequence.tsx` 只管畫面；成功率、增值、次數與損毀規則不變。
- 背景分頁暫停演出計時；素材載入失敗時不消耗卷軸，可關閉提示重試。
- `scripts/forge-review.mjs` 驗證三種結果、連點只扣一次、接續強化、靜音、背景暫停、桌面／手機定位與降低動態偏好。
