# 森境旅人技能動作描述與接入紀錄

紀錄日期：2026-10-15。紀錄版本：1.0。狀態：美術素材完成，尚未接入遊戲技能。

這批素材延續目前森境旅人造型，共四職業、12 組、96 幀。每組 8 幀，包含預備、出招與收勢；首尾共用同職業待機幀。所有動作固定原點，角色的跳躍與前後位移由遊戲程式處理。以下內容記錄已製作的視覺動作及接入需求，未定義傷害、冷卻、消耗或命中規則。

- [PNG 圖集](export/hero-motions.png) 與 [Aseprite 圖集資料](export/hero-motions.sheet.json)。
- [動畫時間與對齊資料](export/motions.json)：目前實際匯出的數值來源。

本文 F0–F7 為單一動作的零起算幀；全域幀為圖集內零起算編號，範圍含首尾。毫秒數以動畫開始為 0，事件落在指定幀的起點。表內時間均為 1× 播放速度；若播放速度為 s，實際時間應除以 s。應以動畫時間／跨幀事件排程，避免低幀率跳過出手幀，亦避免同一次播放重複觸發事件。

## 各動作描述

### 1. 原地旋轉跳躍

動作 ID：`jump_spin`。

原地收腿並繞身體垂直軸轉一圈，依序呈現側面、背面與正面，披風隨轉身展開。適合跳躍轉身或空中技能的動作演出；本身沒有攻擊出手事件。

**逐幀演出**：F0 持劍待機 → F1 蹲伏預備 → F2 收腿起轉 → F3 背面旋轉 → F4 另一側側面旋轉 → F5 正面收腿 → F6 朝原方向收勢 → F7 共用待機。

**每幀時間**：90 / 100 / 80 / 80 / 80 / 80 / 90 / 120 ms，總長 720 ms。

**武器銜接**：單手劍保持握持；旋轉中的前後遮擋已畫入角色。

**視覺事件**：沒有攻擊釋放事件。

**接入注意**：由程式施加跳躍弧線，並依實際落地時機銜接收勢；不要用貼圖包圍盒的位置推算世界位移。

### 2. 拔刀斬

動作 ID：`draw_slash`。

先將刀移向鞘口、壓低重心握柄，再抽刀向前橫斬，最後回到低位持刀。此動作包含入鞘準備，因此可從本套件的持劍待機開始。

**逐幀演出**：F0 持劍待機 → F1 導刀入鞘 → F2 低姿握柄蓄勢 → F3 抽刀過渡 → F4 向前拔刀橫斬 → F5 低位延伸收刀 → F6 回收手臂 → F7 共用待機。

**每幀時間**：90 / 100 / 140 / 70 / 50 / 70 / 90 / 120 ms，總長 730 ms。

**武器銜接**：刀鞘、刀身與手掌一併繪製；出鞘到斬出的接觸關係由逐幀原畫表現。

**視覺事件**：`visual_strike_1` 在 400 ms（F4／全域幀 12）。

**接入注意**：可在出刀時對齊斬擊特效；是否附帶前衝、攻擊範圍與命中時段由遊戲設定。

### 3. 橫斬

動作 ID：`slash_horizontal`。

將持刀手向後上方蓄勢，經過身前向前方橫切，再向下收刀。可作為一般揮砍或連段中的橫向攻擊演出。

**逐幀演出**：F0 持劍待機 → F1 向後引刀 → F2 後上方蓄勢 → F3 刀身經過身前 → F4 向前橫切 → F5 向下隨勢 → F6 低位回收 → F7 共用待機。

**每幀時間**：80 / 80 / 110 / 55 / 50 / 70 / 90 / 120 ms，總長 655 ms。

**武器銜接**：單手持劍；刀身跟隨手腕從高位穿過身前到低位。

**視覺事件**：`visual_strike_1` 在 325 ms（F4／全域幀 20）。

**接入注意**：斬擊殘影與命中區域需另行建立；素材沒有包含刀光判定。

### 4. 上挑斬

動作 ID：`slash_rising`。

先壓低重心將刀移至低位，再沿斜向上方挑斬，完成高位收刀後回到待機。適合作為上挑或連段方向變化。

**逐幀演出**：F0 持劍待機 → F1 壓低重心引刀 → F2 低位準備 → F3 上挑過渡 → F4 斜向上挑斬 → F5 高位隨勢 → F6 降低刀位 → F7 共用待機。

**每幀時間**：80 / 90 / 110 / 55 / 50 / 80 / 100 / 120 ms，總長 685 ms。

**武器銜接**：低位持刀逐步轉為舉刀，刀與手不另外疊圖。

**視覺事件**：`visual_strike_1` 在 335 ms（F4／全域幀 28）。

**接入注意**：敵人浮空、角色升空或向上判定都需遊戲另行定義，動畫不包含這些機制。

### 5. 雙手重劈

動作 ID：`cleave_heavy`。

雙手將刀舉過頭部，保留較長的高位蓄勢，再向前下方重劈，彎膝收勢後恢復待機。此組節奏偏重，強調蓄勢與收招。

**逐幀演出**：F0 持劍待機 → F1 抬刀 → F2 雙手舉刀 → F3 頭頂蓄勢 → F4 向前下方重劈 → F5 低位隨勢 → F6 抬身回收 → F7 共用待機。

**每幀時間**：80 / 100 / 110 / 150 / 55 / 90 / 110 / 120 ms，總長 815 ms。

**武器銜接**：出招中雙手握同一刀柄；首尾仍使用劍系共用待機。

**視覺事件**：`visual_strike_1` 在 440 ms（F4／全域幀 36）。

**接入注意**：頓幀、震動、衝擊波與重擊傷害屬後續機制；不要直接把 815ms 當作冷卻時間。

### 6. 定點突刺

動作 ID：`thrust`。

將持刀手收近身體，使刀身朝向前方，再伸手直刺並沿原方向回收。適合作為窄幅、直線方向的攻擊動作。

**逐幀演出**：F0 持劍待機 → F1 收手至腰側 → F2 刀身對準前方 → F3 前伸過渡 → F4 伸手直刺 → F5 收回前臂 → F6 放低刀身 → F7 共用待機。

**每幀時間**：80 / 100 / 100 / 60 / 55 / 80 / 90 / 120 ms，總長 685 ms。

**武器銜接**：刀身在前伸與收回時保持與持刀手連接。

**視覺事件**：`visual_strike_1` 在 340 ms（F4／全域幀 44）。

**接入注意**：素材只有伸臂，沒有角色前衝；衝刺距離、穿透與直線判定交給程式。

### 7. 聚能施法

動作 ID：`mage_cast`。

持杖保持身體穩定，另一手在胸前聚能，轉掌向前施法，最後收回。原畫有掌心附近的小型魔法亮點。

**逐幀演出**：F0 持杖待機 → F1 施法手靠近胸口 → F2 掌心聚能 → F3 轉掌向前 → F4 伸掌釋放 → F5 伸掌隨勢 → F6 收回施法手 → F7 共用待機。

**每幀時間**：80 / 100 / 130 / 100 / 70 / 90 / 100 / 120 ms，總長 790 ms。

**武器銜接**：法杖保持在握持手上；施法手從胸前轉為前伸掌心。

**視覺事件**：`visual_spell_release` 在 410 ms（F4／全域幀 52）。

**接入注意**：魔法彈、射線或區域特效需另外建立；掌心亮點不是可獨立移動的投射物。

### 8. 法杖爆發

動作 ID：`mage_staff_burst`。

雙手提杖並向上蓄勢，再把杖頭朝前推出以表現爆發，隨後收回法杖。動作幅度比聚能施法更大。

**逐幀演出**：F0 持杖待機 → F1 提起法杖 → F2 雙手準備 → F3 舉杖蓄勢 → F4 杖頭向前爆發 → F5 雙肘回收 → F6 放低法杖 → F7 共用待機。

**每幀時間**：80 / 100 / 110 / 140 / 65 / 90 / 110 / 120 ms，總長 815 ms。

**武器銜接**：雙手與杖身合圖，杖頭的近距離光效已包含在原畫。

**視覺事件**：`visual_spell_release` 在 430 ms（F4／全域幀 60）。

**接入注意**：爆發範圍、法陣、擊退與額外光效由遊戲決定，素材沒有既定的範圍傷害。

### 9. 拉弓蓄力射擊

動作 ID：`archer_aimed_shot`。

依序取箭、搭箭、拉弓並停留在滿弦姿勢，再放弦射出與收弓。此組有較明顯的瞄準蓄力節奏。

**逐幀演出**：F0 低位持弓 → F1 取箭 → F2 搭箭 → F3 拉弓過渡 → F4 滿弦瞄準 → F5 放弦 → F6 收弓 → F7 共用待機。

**每幀時間**：80 / 100 / 90 / 110 / 160 / 65 / 90 / 120 ms，總長 815 ms。

**武器銜接**：弓、弦、搭弦中的箭與手部一併繪製；放弦幀起不保留搭弦箭。

**視覺事件**：`visual_arrow_release` 在 540 ms（F5／全域幀 69）。

**接入注意**：在放弦視覺事件建立箭矢；如果實作按住蓄力，可延長滿弦姿勢，但需同步更新事件時間。

### 10. 快速接續射擊

動作 ID：`archer_quick_shot`。

快速搭箭並斜向拉弓，較短停留後放弦，手回到箭袋附近準備接續。這是一發快速射擊的動作，可由遊戲安排多次播放。

**逐幀演出**：F0 低位持弓 → F1 快速搭箭 → F2 拉弓過渡 → F3 斜向滿弦 → F4 放弦 → F5 手回箭袋 → F6 收弓準備 → F7 共用待機。

**每幀時間**：60 / 65 / 65 / 90 / 50 / 60 / 70 / 100 ms，總長 560 ms。

**武器銜接**：箭搭在弓弦上，放弦後由角色貼圖移除；弓身持續由握弓手支撐。

**視覺事件**：`visual_arrow_release` 在 280 ms（F4／全域幀 76）。

**接入注意**：每次播放只代表一次射箭；連射次數、瞄準角度、射速與箭矢彈道另行定義。

### 11. 雙刃連斬

動作 ID：`assassin_dual_slash`。

雙手短刃在胸前交叉蓄勢，先以一刀向前橫切，另一刀接續斜斬，最後交叉收勢並恢復待機。兩個出刀姿勢應分別記錄。

**逐幀演出**：F0 雙刃待機 → F1 交叉蓄勢 → F2 第一刀橫切 → F3 換手蓄勢 → F4 第二刀斜斬 → F5 低位交叉收勢 → F6 分開雙刃回收 → F7 共用待機。

**每幀時間**：70 / 95 / 50 / 65 / 50 / 80 / 90 / 120 ms，總長 620 ms。

**武器銜接**：每手一柄短刃。正式原畫採用 v2，已修正第五姿勢多出的手臂。

**視覺事件**：`visual_strike_1` 在 165 ms（F2／全域幀 82）；`visual_strike_2` 在 280 ms（F4／全域幀 84）。

**接入注意**：視覺有兩刀，但命中次數、傷害及資源消耗仍由技能邏輯決定；不要只因兩個視覺事件就重複結算。

### 12. 飛刃投擲

動作 ID：`assassin_throw`。

一手保留短刃護身，另一手舉刃後向前投擲；出手後呈現空手，再從腰間補刃回到雙刃待機。

**逐幀演出**：F0 雙刃待機 → F1 舉起投擲刃 → F2 後擺蓄勢 → F3 手臂向前送出 → F4 張手釋放 → F5 空手回收 → F6 從腰間補刃 → F7 共用待機。

**每幀時間**：70 / 90 / 110 / 55 / 50 / 80 / 100 / 120 ms，總長 675 ms。

**武器銜接**：投擲手在釋放幀後為空手，另一手持刃不變；飛行中的刀沒有畫入角色。

**視覺事件**：`visual_blade_release` 在 325 ms（F4／全域幀 92）。

**接入注意**：在張手幀建立獨立飛刃投射物；投射物圖像、速度、回收與穿透皆需另行提供或設定。

## 遊戲接入約定

1. 以動作 ID 選擇對應 tag，保留各幀的 duration，預設以單次動畫播放。預覽循環僅供檢視，不代表技能自動連發。
2. 未裁切畫布固定 128×128，root 為 (64,120)，面向左。圖集已裁掉透明邊界，繪製時必須套用 `spriteSourceSize` 與 `sourceSize` 還原位置，不能將裁切圖塊直接置中。
3. 所有幀的 root motion 為 (0,0)。地面姿勢以腳底對齊；旋轉動作以骨盆 (64,102) 對齊。蹲伏、伸手與收腿只是局部姿勢，不是碰撞體移動。向右時繞 root 鏡像。
4. 這批角色、衣服、武器已合圖。播放時由整體動畫替代紙娃娃；結束時恢復原狀。此套件未提供獨立武器層、握把錨點或投射物發射錨點。若要支援換裝換武器，需另做分層或專用版本；投射物出生位置也需實際對位。
5. 同職業首尾像素完全相同，可用首幀作本套件的持武器待機。舊版 `overall_0001` 的姿勢不同，接回舊版待機要檢查跳幀；跨職業也需處理武器替換。
6. 視覺事件僅用來對齊程式的攻擊、投射物、音效或特效。實際命中範圍、有效時段、傷害、資源消耗、押注結算及命中次數由技能邏輯決定，不能以每次動畫事件直接替代結算規則。
7. 位移、起跳／落地、擊退、浮空、連射、取消、連段、頓幀及震動都由遊戲實作。若拉長蓄力或改變播放速度，事件必須跟隨動畫時間調整。
8. 新 tag 尚未加入共用 `AVATAR_TAGS` 或職業技能資料。請先決定獨立整體動畫的載入方式，再映射到正式技能 ID；本次紀錄不新增技能機制。

## 接入完成時的驗收項目

- 左右朝向與所有動作的 root 對齊，沒有因為圖集裁切而漂移。
- 首尾切換、連段與取消時只顯示一個角色、一套武器。
- 事件在一次播放內各觸發一次；低幀率、加速、暫停與取消都不漏發或補發已失效事件。
- 弓箭手於放弦幀產生箭，刺客於空手幀產生飛刃；出生點與手／弓對齊。
- 雙刃兩個視覺出手點與技能實際命中、消耗規則相符。
- 程式位移與動畫局部姿勢分開，碰撞體及地面接觸保持正確。
